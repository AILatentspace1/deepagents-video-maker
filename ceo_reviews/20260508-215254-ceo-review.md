## Critical gap

### 1. Real video proof is still missing

**CRITICAL GAP:** The project can now produce a `final/video.mp4` path in the golden render smoke, but the file is explicitly a simulated renderer-output fixture. That is acceptable for pipeline ratification, but it does not answer the buyer/user question: "show me the video this agent made."

**Impact:** The team may overestimate product readiness because all milestone states and package artifacts are green while the core user-visible output is not yet proven playable or visually acceptable.

**Recommendation:** Add a third deterministic ladder step, for example `pnpm golden:playable`, that uses a tiny approved script and minimal Remotion composition to render an actual playable MP4. If local Chromium/ffmpeg dependencies are missing, skip with a crisp environment diagnostic rather than replacing it with a fake video.

## Scope proposals

### 1A. Accepted — add a playable golden render tier

Create a real-render proof separate from `golden:script` and simulated `golden:render`.

- Keep `golden:render` as the fast plumbing test.
- Add `golden:playable` or equivalent as the product-demo proof.
- Require `ffprobe`/duration validation on the real file.
- Document exactly which command a stakeholder should run to see the video.

### 1B. Deferred — UI live-thread demo script

The backend now emits `video_maker`, and the UI consumes it, but this run did not prove a browser-visible local LangGraph thread walking through milestones. Defer until after the playable render tier unless the immediate goal is a stakeholder UI demo.

### 1C. Deferred — make publish-readiness a hard quality gate

Do **not** turn publish readiness into a hard blocker yet. Keep it advisory until there is a real rendered artifact and a human/taste-review loop. Hard-gating simulated output would create false confidence.

## Product stance

The right promise is not "fully autonomous video creation" yet. The stronger near-term promise is:

> A DeepAgents-native producer that turns vetted sources into a structured script, generates a Remotion package behind explicit approval gates, and exposes every milestone/artifact in an operator UI.

That promise is now credible. The missing proof is only the last mile: a real, deterministic video artifact that can be played and judged.
